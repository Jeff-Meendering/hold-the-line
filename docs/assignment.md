# Final Project: AI-Assisted Software Engineering

Due: Sun Dec 6, 2026 11:59pm. 220 points.

## Objective

Your goal is to design and build a complete, functional software application using AI as your primary engineering collaborator.

You may build a web, mobile, or desktop application.

This project is not just about the final application. It is also about how well you use AI throughout the Software Development Life Cycle (SDLC).

You will be evaluated on your ability to plan, guide, manage, and critically evaluate AI tools while making sound software engineering decisions.

Important: You must document your interactions with AI, including screenshots of all prompts used throughout the project.

## 1. Project Requirements

### A. Build a Complete Application

Develop a functional software system in one of these formats:

- Web application
- Mobile application
- Desktop application

Your application should demonstrate the engineering practices covered throughout this course, including prompt engineering, context engineering, spec engineering, loop engineering, model selection, and so on. Your knowledge of Software Engineering should be shown through all the directions you give to AI.

### B. Use Multiple AI Tools

You must use more than one AI model and tool during the project.

For example, you might use different AI tools for planning, architecture, UI design, implementation, testing, or documentation.

The goal is not simply to use as many tools as possible. Instead, demonstrate that you understand which tools to use, when to use them, and how to coordinate their work effectively.

### C. Apply AI Throughout the SDLC

Your project must cover and document all six areas below.

1. Project Planning
   - Define the purpose and scope of your application.
   - Identify important constraints and assumptions.
   - Create a full and rich software plan.

2. Requirements Engineering
   - Define functional and non-functional requirements.
   - Create user personas.
   - Write user stories.

3. System Design and UI Design
   - Create the system design.
   - Plan the user interface and user experience.
   - Explain important design decisions.

4. Implementation
   - Use AI to generate, improve, and refine the application.
   - Show how your implementation evolved through multiple iterations.

5. Testing
   - Develop a testing strategy.
   - Create manual and/or automated tests.
   - Verify that the application behaves as expected.

6. Documentation
   - Produce clear, organized, and professional documentation explaining your system and engineering decisions.

## 2. Document Your AI-Assisted Workflow

You must provide evidence showing how you worked with AI, not just what AI produced.

Your documentation must include:

- Screenshots of all prompts used during the project.
- Important iterations showing how you improved prompts, dealt with bugs, and results you achieved.
- Examples of situations where AI produced useful results.
- Examples where AI made mistakes, failed, or provided misleading information.
- Examples where you questioned, corrected, or rejected AI-generated solutions.

Your documentation should demonstrate that you remained in control of the engineering process rather than blindly accepting AI output.

## 3. What You Must Submit

### A. Public GitHub Repository

Create a public GitHub repository containing your complete project.

Your repository must include:

- All source code needed for the application.
- All required project assets.
- A /screenshots folder.
- A complete README.md file.
- Supporting documentation and AI context files.

Your repository must be public so your instructor can access and evaluate it.

### B. Screenshots Folder

Create a folder named /screenshots in your repository.

Include:

- Screenshots of all AI prompts and interactions, include the screenshots for planning.
- Screenshots of the completed application.
- Screenshots of intermediate development steps (optional but encouraged).

Organize and name the screenshots so they are easy to understand and reference.

### C. README.md

Your README.md is a critical part of your final grade. It must contain the following sections:

1. Project Overview
   - Project name.
   - Purpose and main features of the application.

2. Architecture Summary
   - Overview of the system architecture.
   - Main technologies and important design decisions.

3. AI Models and Tools Used
   - List each AI model and tool used.
   - Explain the role each played in your project.

4. AI Engineering Analysis
   - What AI tools did particularly well.
   - Where AI struggled or failed.
   - Tradeoffs and challenges you encountered.
   - Prompting strategies that worked and those that did not.

5. Engineering Reflection
   - How you would have approached the project without AI.
   - What AI helped you accomplish more effectively.
   - What AI made more difficult or potentially worse.
   - What you learned about engineering software with AI.

6. Supporting Documentation and Context Files

   Include and reference the files you used to guide AI, such as:

   - architecture.md — System architecture and technical decisions.
   - security.md — Security considerations and requirements.
   - CLAUDE.md (or equivalent) — Instructions and context provided to AI coding agents.
   - Any other context files, guidelines, or instructions used during development.

## 4. How Your Project Will Be Graded

- Prompt Quality: Clear, structured prompts that demonstrate purpose, planning, and iterative improvement.
- Engineering Rigor: Strong software engineering principles applied when directing and evaluating AI.
- AI Orchestration: Effective coordination of multiple AI tools and models, with clearly defined responsibilities.
- System Completeness: All steps to the SDLC were followed and respected with proper engineering care.
- Critical Reflection: Thoughtful analysis of AI's strengths, weaknesses, mistakes, risks, and your own engineering decisions.

## 5. Important Reminders

Generating an application with AI is not enough to earn a high grade.

The strongest projects will demonstrate:

- AI control: You actively direct and manage AI rather than allowing it to make every decision.
- Engineering judgment: You apply software engineering principles when making technical decisions.
- Iteration: You refine prompts, evaluate results, and improve solutions.
- Critical thinking: You recognize AI mistakes, limitations, and potential risks.
- Intentional orchestration: You choose the right AI tools for specific tasks and coordinate them effectively.

Projects with superficial prompts, little iteration, or blind acceptance of AI-generated results will receive significantly lower grades, even if the application appears complete.

Remember: You are the software engineer. AI is your engineering collaborator.
